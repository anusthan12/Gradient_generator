# Gradient Generator

A random gradient color generator built with vanilla JavaScript — useful for developers looking for fresh color combinations for their projects.

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)](#)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)](#)
[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)](#)

## Features

- Generates random gradient color pairs using JavaScript loops
- One-click copy of CSS gradient code
- Instant preview of the generated gradient
